## Project Description

This project demonstrates stack and queue data structures using arrays and linked lists. It includes a menu-driven program, a balanced brackets checker, a print queue simulation, and a test driver.

## Files Included

- array_stack.py — Implements a stack using an array.
- linked_stack.py — Implements a stack using a linked list.
- array_queue.py — Implements a circular array queue.
- linked_queue.py — Implements a queue using a linked list.
- node.py — Defines the node used by linked-list structures.
- main.py — Provides the menu-driven program.
- applications.py — Contains the balanced brackets checker and print queue simulation.
- test_driver.py — Tests the stack and queue operations, including underflow, overflow, and circular wrap-around.
- analysis.md — Contains the answer to the analysis question.

## Requirements

- Python 3
- No external libraries are required.

## How to Run the Main Program

Open a terminal in the project folder and run:

python main.py

Choose an implementation from the menu and select an operation. The program displays the current state after each operation.

## How to Run the Tests

Run the following command:

python test_driver.py

The tests check the behavior of the four data structures, including error conditions and circular queue wrap-around.

## How to Run the Applications

Run:

python applications.py

This demonstrates balanced brackets checking and a print queue that processes jobs in First In, First Out (FIFO) order.

## Conclusion

This project demonstrates how stacks and queues work using arrays and linked lists. It also shows how to handle underflow and overflow and how a circular queue reuses available array positions.
