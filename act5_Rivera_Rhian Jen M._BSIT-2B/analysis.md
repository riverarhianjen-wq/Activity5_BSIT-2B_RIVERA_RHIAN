A linked-list stack pushes at the head because it can add a new node directly without searching through the list. This makes push and pop operations O(1), or constant time. If the stack uses the tail, removing the last node in a singly linked list may require searching for the previous node, which takes O(n) time. An array queue must be circular so that it can reuse empty spaces after dequeue operations. The modulo operator allows the front and rear positions to return to the beginning of the array, making enqueue and dequeue efficient.
